# Analizador-2026-

Repositorio para el "Analizador de fondos" / análisis de oportunidades de Mercado Público (Compras Ágiles) en Chile.

## Prompts guardados

- `prompts/analista-compras-agiles.md`: Prompt maestro para actuar como analista senior de compras públicas y evaluar si conviene participar en una Compra Ágil (estudio de mercado, costos, rentabilidad, riesgos, precio óptimo de oferta). Úsalo como instrucción base cada vez que se pida analizar una Compra Ágil de Mercado Público en este proyecto.
